# 📦 Inventory & Service Delivery Tracker

A full-stack B2B application to manage inventory and track supply requests across multiple Service Delivery Points (SDPs).

---

## 🚀 Features

### 📦 Inventory Management
- Add & view items
- Track quantity and threshold
- ⚠ Low stock alerts

### 📄 Request System
- SDPs can request items
- Admin can:
  - Approve ✅
  - Reject ❌
  - Mark as Delivered 🚚

### 🔐 Authentication
- User Signup & Login
- Token-based authentication (JWT)

### 🎨 UI Features
- Clean dashboard layout
- Theme switcher:
  - 🌸 Pink (default)
  - ☀ Light
  - 🌙 Dark

---

## 🛠 Tech Stack

### Backend
- FastAPI
- SQLAlchemy
- SQLite
- JWT Authentication

### Frontend
- React JS
- Axios
- CSS (Custom UI + Themes)
